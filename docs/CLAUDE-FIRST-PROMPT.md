# Claude Code に最初に貼るプロンプト

スマホウォーズの作業フォルダーを「Code」で開き、以下をそのまま貼り付けてください。

```text
スマホウォーズの共同開発に初めて参加します。今回は開発環境の確認まで実行してください。ゲームの実装、コミット、push、PR作成、デプロイは次の開発依頼からです。

1. ルートの CLAUDE.md と参照先の AGENTS.md、README.md、docs/DEVELOPMENT-HANDOFF.md を読み、ゲームの入口、ロジック、セーブ、テスト、公開手順を把握してください。
2. Gitのルート、origin（Yoshi2026s/famicom-wars）、現在のブランチ・コミット、作業ツリーとworktreeを確認してください。対象が違えばそこで知らせてください。対象が合えば origin をfetchし、origin/main との差と進行中のPRを確認してください。別の作業者の変更と未追跡ファイルは保全してください。
3. Node.jsの実バージョンを調べ、24系でリポジトリ直下の node --test を実行してください。既定が別バージョンなら導入済みの24系を探して使い、見つからなければ、その点と実行できた範囲を報告してください。通常のテストには追加パッケージやAPIキーは不要です。
4. Claudeデスクトップではプロジェクトのプレビュー「スマホウォーズ」を、CLIでは空きポートで dev-server.mjs を起動してください。テスト専用のブラウザーをスマホ縦画面にして、「湾岸の攻防」の盤面、「次の部隊」での切替、「全体図」の開閉を実際に確認してください。自分で起動した一時サーバーは確認後に終了してください。
5. 日本語で、共同開発を始められるかを最初に答えてください。ブランチとmainとの差、テストの通過件数、実際に操作した環境・項目、未確認事項を簡潔に報告してください。追加の機能開発は次の依頼を待ってください。
```
