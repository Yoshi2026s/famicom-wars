# スマホウォーズ

[GitHub Pages で遊ぶ](https://yoshi2026s.github.io/famicom-wars/)

## 湾岸の攻防

26列×18行のマップで、陸・空・海の部隊を指揮します。マップは新しい対戦ごとに `public/map-generator.js` がランダムに作ります。西半分を作って東へ左右反転するため、両陣営の地形・施設の種類と数・距離は同じです。両本拠地を結ぶ陸路（歩兵と車両）、すべての施設への陸路、港どうしの海路がある配置だけを採用します。マップは保存データに含まれ、再開時は同じマップに戻ります。両陣営とも部隊なしで開始し、最初のターンに本拠地・工場などで生産します。いずれかの陣営の部隊がすべて撃破されると決着しますが、まだ部隊を出していない陣営は全滅扱いになりません。以前の固定マップ（`public/coastal-scenario.js`）の保存データもそのまま再開できます。タイトルの「中断から再開」では、固定マップの対戦に「以前の固定マップ」と表示します。ランダムマップで遊ぶときは「新規ゲーム」を選びます。

歩兵が空いている敵本拠地に入ると勝利です。いずれかの陣営が全滅した場合も決着します。都市・工場・飛行場・港も歩兵で占領でき、施設を確保すると収入や前線の生産・回復に役立ちます。湾岸の攻防では施設ごとに占領値10があり、歩兵が占領するたびにそのHP分だけ減ります。HP10の歩兵なら1回、HPが少ない歩兵は複数ターンかけて占領します。施設に残ったまま次のターンに歩兵を選び、自分のマスを選ぶと占領を続けられます。歩兵が施設を離れるか撃破されると進行は10に戻ります。占領中の施設には進行バーが表示され、占領完了や勝敗決定時には演出が入ります（タップで閉じられます）。

### 移動と戦闘

盤面か味方部隊一覧でユニットを選び、移動先または攻撃対象を指定します。味方部隊のいるマスは移動力が足りれば通過できますが、止まることはできません。敵部隊のいるマスは通過できません。移動や攻撃の対象ではないマスを選ぶと、地形・防御・施設・部隊などのマス情報を表示します。移動先を選ぶと部隊がそのマスへ仮に移動し、画面下で「移動を確定」か「キャンセル」を選びます（元のマスには「元」の印が付きます）。キャンセルすると元のマス・未行動・選択中の状態に戻ります。仮の移動先から攻撃できる敵をタップすると攻撃の確認画面になり、「攻撃する」で移動と攻撃をまとめて確定します（攻撃の確認でキャンセルすると仮の移動に戻ります）。占領は移動を確定したときに進みます。確定前に閉じた場合は移動前の状態で再開します。攻撃の確認画面には攻撃と反撃によるHPの変化が表示されます。

- 地上部隊は道路を使って対岸へ進めます。森・湿地・山の防御や、車両が入れる地形の違いを使い分けます。
- 航空部隊は陸地や水域を越えて移動できます。地形による防御効果は適用されません。
- 艦船は外海・浅瀬・港を航行できます。浅瀬に入るときは移動力を2消費します。
- 射程は上下左右の距離で数えます。兵種ごとに射程と攻撃できる相手が異なり、支援車・自走砲・ロケット砲・戦艦は移動したターンに先制攻撃できません。
- 与えるダメージは、兵種の攻撃力に相性補正を加え、相手の地形防御を引いた値に、攻撃側の残りHPの割合（戦力）を掛けて四捨五入した値です（最低1）。HPが半分なら与えるダメージもおよそ半分になります。攻撃の確認画面に戦力を表示します。相手が生き残って反撃できる条件を満たす場合は、被弾後のHPで反撃します。

戦闘画面では先攻と反撃を表示します。歩兵はHPと同じ人数、ほかの部隊はHP2につき1機の編隊で残機を表し、空中戦は空、艦船戦は海の背景になります。「演出をスキップ」で結果を確認し、「マップに戻る」で続行できます。敵は占領、攻撃、反撃で受ける損害、増援に使える施設などを考慮して動き、盤面では行動中の部隊と経路を確認できます。

### 生産と回復

初期資金は各陣営10,000です（固定マップの旧保存データは8,000で開始したものです）。2ターン目以降は毎ターン1,000に加え、所有都市1つにつき1,000の資金が入ります。自軍の生産施設は、空いていれば1ターンに1部隊を生産できます。新しい部隊はHP10で出撃し、次のターンから操作できます。稼働中の部隊は陣営ごとに14までです。

| 部隊 | 生産施設 | HPを回復できる施設 |
| --- | --- | --- |
| 歩兵・偵察車・支援車・戦車・自走砲・ロケット砲・対空車 | 本拠地、工場、いずれかの本拠地から上下左右に数えて3マス以内の自軍都市 | 本拠地、工場、都市、飛行場、港 |
| 攻撃ヘリ・戦闘機・爆撃機 | 飛行場 | 飛行場 |
| 哨戒艇・駆逐艦・戦艦 | 港 | 港 |

自軍の対応施設にいる生存部隊はターンが進むとHPを最大2回復します（最大10）。回復には1HPあたり兵種価格の1割の資金を使い（例：戦車は1HP 400）、収入の後に支払います。資金が足りないときは払える分だけ回復します。CPUも同じルールです。「生産」の印があるマスか、スマホの画面下にある「ユニット生産」から生産施設と部隊を選べます。

## 操作と自動保存

起動するとタイトル画面になります。背景は `public/scene-art.js` の `titleScene` がコードで描く夕暮れの海岸（対応ブラウザーでは別スレッドで描画）で、その上に `unit-art.js` の部隊を重ねます。端末の「動きを減らす」が有効なときは背景と部隊を動かしません。タイトルでは「新規ゲーム」（CPUの強さを選んで、ランダムマップで開始）か「中断から再開」（保存された対戦があり、決着していないときだけ選べます）を選びます。敵の手番の途中で中断した対戦は、再開を選んでから残りの行動を続けます。

ゲーム中は画面上部の「メニュー」から次を選べます。

- **中断してタイトルへ**：進行を保存してタイトルに戻ります（確定前の仮の移動は取り消します）。
- **最初から**：同じマップ・同じCPUの強さでターン1からやり直します。確認画面で「最初からやり直す」を押したときだけ実行します。
- **降伏**：対戦を敗北で終えます。確認画面で「降伏する」を押したときだけ実行し、取り消せません。決着後は選べません。

スマホは縦向きです。盤面を上下左右にスワイプできます。マスに座標は表示せず、位置は地形や施設の名前で示します。「次の部隊」で行動できる味方へ切り替え、「全体図」で表示位置を移動できます。「戦況」には部隊・資金・施設・行動履歴・地形の凡例があります。キーボードではTabで盤面に入り、矢印キーで移動し、Enterまたはスペースで選びます。

敵部隊のマスをタップすると、その部隊の詳細が画面下に開きます。味方部隊は選んだあと「詳細」ボタンで開きます（選択は解除されません）。詳細では次の行動で移動できるマス（青）と攻撃が届くマス（赤）を盤面に表示し、種別・価格、移動と通れない地形、射程、反撃・占領の可否、攻撃対象、現在地の防御、特性、得意な相手（与ダメージの目安）・苦手な相手（受けるダメージの目安）・攻撃できない相手を確認できます。「閉じる」またはEscで閉じます。

### CPUの強さ

画面上部の「CPU」ボタンか、決着後の「もう一度対戦する」から新しい対戦を始めるときに3段階から選びます。選んだ強さは保存データに含まれ、再開しても変わりません。以前の保存データは「ふつう」で再開します。

| 強さ | CPUの収入 | 判断 |
| --- | --- | --- |
| やさしい | 75% | 行動の評価に小さなばらつきを加え、反撃や危険の重みを35%に下げる |
| ふつう | 100% | 従来どおり |
| つよい | 125% | 反撃や危険の重みを130%に上げ、より慎重に避ける |

プレイヤー側の資金・収入はどの強さでも同じです。

進行は、移動・戦闘・生産・ターン進行に合わせて同じブラウザーに自動保存されます。戦闘演出の途中で閉じた場合は確定した結果から、敵の手番の途中なら残りの行動から再開します。以前の「はじまりの草原」の対戦はそのマップで再開します。「遊び方」の「湾岸の攻防を開く」で新マップを遊べます。両方の進行は別々に保存され、「遊び方」から切り替えられます。

iPhoneのSafariでは、共有メニューの「ホーム画面に追加」から専用アイコンを置けます。Safariに保存した対戦の続きをホーム画面から開く場合は、「Webアプリとして開く」が表示されたらオフにして、ゲームのページを追加してください。AndroidのChromeでは、メニューからウェブサイトのショートカットを作れます。ブラウザーのサイトデータを消すと対戦の保存も消えます。

BGMと効果音は個別に設定でき、選んだ設定はブラウザーに保存されます。BGMは最初のタップやクリックから再生されます。端末の「動きを減らす」を有効にすると、盤面や戦闘画面のアニメーションを抑えます。

## ローカル開発

Codex と Claude Code で開発するときは、[共同開発ガイド](docs/DEVELOPMENT-HANDOFF.md) と [Claude Code に最初に貼るプロンプト](docs/CLAUDE-FIRST-PROMPT.md) を使います。

Node.js 24 を使います。追加パッケージのインストールは不要です。

```powershell
node --version
node --test
node dev-server.mjs
```

ブラウザーで http://127.0.0.1:8080/ を開きます。終了するにはターミナルで Ctrl+C を押します。

- `public/` にブラウザーへ配信する HTML、CSS、JavaScript、素材を置きます。
- `test/` に自動テストを置きます。変更後は `node --test` を実行します。

- 盤面・補助背景・部隊やホーム画面アイコンのドット絵の編集元は `scripts/draw-assets.mjs` です。`node scripts/draw-assets.mjs` でPNGを再生成できます。歩兵・偵察車・支援車・戦車の戦闘用画像は待機・構え・発射・反動・被弾・防御・撃破の7コマを1ファイルに格納しています。
- 部隊の絵（マップ・戦闘画面・部隊一覧）は `public/unit-art.js` がブラウザー上で陰影・金属の質感・迷彩を付けて描くオリジナルの3D風イラストです。戦闘用の7コマ（待機・構え・発射・反動・被弾・伏せ・撃破）も同じファイルで描きます。描けない環境では従来のドット絵を使います。
- 戦闘画面の山と草原の背景と、森・山・湿地の遮蔽物は `public/scene-art.js` がブラウザー上で描きます（山は陰影・雪・かすみ、草原は遠近のある草と花）。読み込み後に1回だけ、対応ブラウザーでは `public/scene-worker.js`（別スレッド）で描いて画面を止めないようにし、描けない環境では `highland-dusk.webp` と従来の遮蔽物を使います。
- 作戦マップの地形（道路・川のつながり、海岸線、水深、森、山）と施設の絵は `public/map-art.js` がブラウザー上で描きます。マップごとに1枚のキャンバスへ描くため追加の画像ファイルはありません。描画は `public/map-worker.js`（Web Worker と OffscreenCanvas）が別スレッドで行い、対応していないブラウザーでは最初の表示のあとページ内で少しずつ描きます。描けない環境では従来のドット絵（`scripts/draw-assets.mjs` 製）で表示します。地形の凡例と全体図は従来の素材を使います。
- 戦闘背景 `public/assets/highland-dusk.webp` は組み込みの画像生成で制作し、WebPに変換した素材です。
- BGMの曲データとMP3生成は `scripts/compose-bgm.mjs` にあります。`pnpm install --frozen-lockfile` で生成用の依存関係を取得し、`node scripts/compose-bgm.mjs` でオリジナルの6曲を再生成できます。

## GitHub Pages への公開

1. 公開先の GitHub リポジトリに `main` を push します。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. **Actions → Test and deploy to GitHub Pages → Run workflow** から `main` を選んで初回配信します。配信ジョブが成功したら、ジョブに表示される公開 URL を開いて確認します。

以降は `main` 向けのプルリクエストでテストを実行します。`main` に反映した変更は、テスト成功後に `public/` の内容を自動配信します。プロジェクト用の Pages URL でも動くように、HTML 内の素材リンクは相対パスで指定します。
